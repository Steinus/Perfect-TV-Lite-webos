# Perfect TV Lite 0.3.5

## Исправление навигации в программе передач

- При полноэкранном просмотре EPG (кнопка ↑ во время воспроизведения) **←** на строке передачи переводит фокус на столбец дат слева, а не закрывает окно.
- На столбце дат **↑ / ↓** выбирают день; список программ прокручивается к началу выбранного дня.
- **→** на дате возвращает фокус к выбранной передаче.
- **BACK** закрывает телепрограмму без остановки видео.
- Для боковой программы в меню каналов, где даты расположены справа, оставлена прежняя навигация.
- Нет изменений в потоковом EPG, 24-часовом дисковом кэше, архиве, плейлистах, сохранении настроек и шрифтах.

**Установка:** поверх 0.3.4, без удаления приложения. ID `com.steinus.perfecttvwebos` сохранён.
