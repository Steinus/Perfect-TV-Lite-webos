# Perfect TV Lite 0.3.7 — импорт M3U-файлов и веб-редактор нескольких плейлистов

Тестовая сборка для LG webOS 4.9 и других совместимых версий. Устанавливается поверх 0.3.6 (тот же `com.steinus.perfecttvwebos`).

## Что нового

- **Добавление по файлу M3U/M3U8/TXT через браузер ПК или телефона.** Файл передаётся на телевизор локальным HTTP-запросом и сохраняется **только в сжатом кэше**. Сервис не обращается к исходному URL плейлиста; это обходной путь для случая, когда запрос к провайдеру в 0.3.6 завершается `curl 28` и тайм-аутом Node HTTP.
- **Многопрофильная веб-страница:** до 12 отдельных плейлистов. Можно создавать, переименовывать, менять EPG, активировать и удалять профили; источники M3U — URL и локальный импортированный файл. Интерфейс оформлен в тёмном стиле, похожем на меню телевизора.
- В `Настройки → Плейлисты` на телевизоре появились подсказка про импорт файла и кнопка перехода к QR-инструкции.
- Импортированный файл восстанавливается после перезапуска приложения из кэша. При выборе файла не выполняется интернет-загрузка M3U. При удалении файлового профиля его кэш очищается, если его не используют другие профили.
- После действий в веб-редакторе раздел «Плейлисты» на ТВ остаётся открытым, чтобы можно было добавлять и редактировать несколько профилей подряд.
- Сохранены архив, EPG-кэш с проверкой обновлений через 24 часа, настройки шрифтов, управление пультом и `User-Agent: PerfecktTV` для запросов сетевого сервиса.

## Как загрузить M3U-файл

1. Установить IPK **поверх** предыдущей версии; приложение не удалять.
2. Открыть **Настройки → Плейлисты** на телевизоре и не закрывать этот раздел.
3. На телефоне/компьютере открыть IP телевизора на порту `8098` (например, `http://192.168.1.105:8098/`) и ввести шестизначный код с ТВ. Или открыть ссылку по QR-коду.
4. Нажать **+ Добавить**, указать название и при необходимости адрес XMLTV EPG.
5. Выбрать **Файл M3U → Выбрать файл M3U**, выбрать скачанный `.m3u`/`.m3u8` и нажать **Сохранить**.
6. Через несколько секунд профиль появится в настройках ТВ и загрузит каналы. Для второго и третьего списка повторить шаги 4–5.

**Ограничения:** файл до 12 МиБ (сжатый кэш M3U ограничен 2 МиБ); ссылки потоков в локальном файле должны быть абсолютными HTTP/HTTPS, а не относительными. EPG и сами видеопотоки по-прежнему обращаются к сети, но **файл плейлиста** больше не скачивается заново.

## Хранение

Файловые плейлисты хранятся в `/media/internal/perfect-tv-lite-data/playlist-<хеш>.json.gz` с правами владельца. Профили, выбранный плейлист, настройки и избранное остаются в данных приложения. Разделение файловых профилей осуществляется по внутреннему идентификатору `ptv-file://…`; этот идентификатор **никогда не отправляется в интернет**.

Команда проверки после импорта:

```sh
ls -lh /media/internal/perfect-tv-lite-data/playlist*.gz
```

## Безопасность и совместимость

Веб-редактор работает **только пока открыт раздел «Плейлисты» на ТВ**. Он защищён случайным токеном из QR-ссылки либо временным шестизначным PIN, с ограничением попыток. Трафик локального веб-редактора идёт по обычному HTTP — **не открывать порт 8098 в интернет и не использовать недоверенную Wi-Fi-сеть**.

IPK не меняет механизм прямого видеовоспроизведения и архивной перемотки. Тайм-ауты удалённого HTTP/HTTPS-плейлиста могут сохраняться: **импорт файла позволяет не зависеть от запроса M3U**, но не устраняет возможную сетевую причину. USB-файловый диалог самого webOS не требуется: загрузка осуществляется через браузер телефона или компьютера.

Автотесты проверяют загрузку M3U по файлу без HTTP к провайдеру, запись кэша, повторный запуск, редактирование нескольких профилей, авторизацию веб-страницы, существующий `curl`/Node загрузчик и старые функции интерфейса. **Проверка на физическом LG остаётся необходимой.**
