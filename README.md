# Perfect TV Lite — IPTV для LG webOS

**Текущая тестовая версия: 0.3.7.** Веб-приложение с отдельным сетевым сервисом для LG webOS. Разрабатывалось и проверялось прежде всего на **LG 60UM7100PLB (webOS 4.9)**; работа на других моделях и прошивках не гарантирована.

## Возможности

- Несколько независимых M3U-плейлистов (до 12), группы, поиск, избранное и история просмотра.
- Загрузка M3U по URL **или импорт локального `.m3u` / `.m3u8` через веб-страницу** телевизора.
- XMLTV EPG: потоковое получение/разбор и постоянный сжатый кэш; автоматическая проверка обновлений раз в **24 часа**.
- Телегид, подробное расписание по датам, информация о текущей и следующей передаче.
- Архив/перемотка там, где поток и формат `catchup` поддерживаются провайдером.
- Настройка размеров шрифтов и интерфейс для телевизионного пульта.

## Установка

1. Скачайте [`dist/PerfectTVLite037.ipk`](dist/PerfectTVLite037.ipk).
2. Установите IPK на LG TV с компьютера через **webOS Dev Manager** (или другой доступный установщик).
3. Откройте **Настройки → Плейлисты**, добавьте плейлист и адрес XMLTV EPG, при необходимости.
4. При обновлении **не удаляйте установленное приложение**: установка поверх него должна сохранить настройки и кэш.

Приложение тестировалось на телевизоре с root-доступом. Совместимость с нерутованными устройствами/другими версиями webOS отдельно не подтверждена.

## Загрузка M3U-файла без скачивания по ссылке

1. Скачайте файл плейлиста в личном кабинете IPTV-провайдера **на компьютер/телефон**.
2. На ТВ откройте **Настройки → Плейлисты** и оставьте настройки открытыми.
3. На компьютере откройте URL из QR-кода или `http://IP_ТВ:8098/` и введите показанный на ТВ PIN.
4. В веб-редакторе добавьте профиль → **Файл M3U** → выберите файл → **Сохранить**.

Импортированный плейлист сохраняется на телевизоре в сжатом кэше и при запуске не требует повторного скачивания исходного M3U. Файлы принимаются до **12 МиБ**, а сжатый кэш ограничен **2 МиБ**. Поддерживаются абсолютные HTTP/HTTPS ссылки потоков. Веб-редактор доступен только пока открыт раздел настроек плейлистов и использует локальный HTTP. **Не открывайте порт 8098 в интернет.**

## Управление при просмотре

| Кнопка | Действие |
|---|---|
| ← / → | Предыдущий / следующий канал, карусель |
| ↑ | Расписание текущего канала |
| ↓ | Информация о канале; повторное ↓ — меню избранного, телегида и истории |
| OK | Каналы текущей группы; ← в списке — группы, ещё ← — служебное меню |
| BACK | Закрыть текущее меню |

При просмотре архива ↓ открывает панель информации, Play/Pause, шкалу перемотки и возврат в эфир. Перемотка выполняется после секундной паузы на ползунке.

## Известные ограничения

- В некоторых сетях/у некоторых провайдеров удалённая загрузка M3U по HTTPS завершается тайм-аутом (`curl 28`); используйте импорт файла через локальную веб-страницу.
- Поддержка видеокодеков определяется аппаратным плеером LG/webOS; не все потоки воспроизводятся.
- Для видеопотока LG может отправлять системный User-Agent `WebAppManager` — это не User-Agent сетевого сервиса приложения.
- Архив доступен только для поддерживаемых источников и форматов ссылок.
- Это **тестовая** сборка, а не официальное приложение LG или IPTV-провайдера.

## Исходники и сборка

- `app/` — интерфейс webOS (`index.html`, `app.js`, CSS и иконки).
- `service/` — сетевой сервис, EPG-кэш и веб-редактор.
- `tools/` — сборщик IPK и тесты.
- `dist/` — установочный IPK.

Сборщик запускается через `python3 tools/build_ipk.py`; его текущий путь вывода — `/mnt/data` (при локальной сборке замените `OUT` в скрипте на существующий каталог). Сохранены сторонние уведомления о лицензиях QR-генератора в `service/LICENSE-THIRD-PARTY` и `service/qr/NOTICE.txt`.

**В репозитории нет IPTV-плейлистов и данных учётных записей.** Используйте собственные легальные источники.
